│ KEY FEATURES                                                                 │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  1. Simple Language                                                         │
│     • Grade-5 reading level                                                 │
│     • Short sentences (max 15 words)                                        │
│     • No jargon or technical terms                                          │
│     • Clear, direct communication                                           │
│                                                                              │
│  2. Respectful Tone                                                         │
│     • Culturally appropriate greetings ("Dear Uncle/Aunty")                 │
│     • Warm, patient tone (not condescending)                                │
│     • Treats users with dignity and respect                                 │
│                                                                              │
│  3. Clear Structure                                                         │
│     • Greeting (personal connection)                                        │
│     • Simple Verdict ("This is FALSE")                                      │
│     • Explanation (why in 2-3 sentences)                                    │
│     • What to Do (clear action steps)                                       │
│     • Why It Matters (real-world impact)                                    │
│                                                                              │
│  4. Multi-language Support                                                  │
│     • 80+ languages supported                                               │
│     • Auto-detects user language                                            │
│     • Culturally appropriate terms                                          │
│     • Native language greetings                                             │
